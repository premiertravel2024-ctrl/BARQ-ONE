# BARQ v2.18.2 — تصحيح تجميع المثبّت

28 أكتوبر 2026. هذه مراجعة لحزمة السورس v2.18.2، والإصدار داخل التطبيق يبقى 2.18.2.

## التصحيح

رسالة Inno Setup في الصورة: UsePreviousLanguage must be set to "no" when AppId includes constants.

أُضيف `UsePreviousLanguage=no` مباشرة في قسم `[Setup]` بملف `scripts/installer.iss`. يلزم هذا الإعداد لأن `AppId={code:ApplicationId}` يحتوي على ثابت وقت تشغيل. مرجع Inno الرسمي: https://jrsoftware.org/ishelp/topic_setup_usepreviouslanguage.htm

يبقى معرف التطبيق الأصلي `{9BB70D04-1EC5-4BC6-B811-64B08F5C8977}` في التثبيت العادي، ومسار التثبيت كما هو. اختبار التثبيت المعزول يحتفظ بمعرف مستقل؛ لا ينبغي تشغيله بمعرف النسخة المثبتة لدى المستخدم. لم يتغير أي كود تشغيل أو إعداد مستخدم في هذا التصحيح.

أُضيف فحص في `scripts/verify_release_consistency.py` يرفض غياب الإعداد أو قيمته غير الصحيحة في قسم Setup قبل npm وPyInstaller. لا يكتفي بوجود النص في تعليق أو قسم آخر. هذا فحص مبكر لقاعدة موثقة، وليس بديلًا عن تجميع Inno الفعلي. تم تحديث أدلة البداية لإزالة أسماء نواتج الإصدارات القديمة من تعليمات البناء الحالية.

## التحقق الفعلي

- المجموعة الكاملة على Linux/Python 3.11: 753 اختبارًا ناجحًا و65 اختبارًا فرعيًا، دون فشل. بقي تحذير إهمال Starlette السابق.
- فحص اتساق الإصدار وفحص اكتمال المصدر نجحا.
- خمس حالات للفحص المبكر: قبول التصحيح، ورفض الإعداد المحذوف، والتعليق فقط، والقسم الخطأ، وقيمة yes. النتائج في verification/v2.18.2-installer-fix/preflight-checks.json.
- الأرشيف فُحص بـCRC وبصمات SHA256 لكل ملفات السورس.
- لم يُعد بناء React لأن هذا التصحيح لا يغير الواجهة أو إصدارها. أصول React وأدلة اختبارها من حزمة v2.18.2 السابقة محفوظة.
- لم يُشغّل Inno Setup أو يُبنَ EXE جديد هنا. لا توجد أداة Windows/Wine في البيئة، وتعذر تنزيل المترجم عبر الشبكة. لا يُعد هذا تقرير نجاح لتجميع Windows أو فحص المثبّت المصحح.

## الاستخدام

فك الأرشيف في مجلد جديد، وافتح مجلد BARQ، ثم شغّل BUILD_BARQ.bat. لا تستخدم مجلد staging القديم ولا تشغّل installer.iss منفردًا. لا تتجاوز اختبارات EXE أو التثبيت. عند نجاح جميع المراحل تُنشأ release/BARQ_Setup_2.18.2.exe وBARQ_Portable_2.18.2.zip وعلامة build-ok-v2.18.2.marker.

إصلاح إغلاق اتصالات SQLite من v2.18.2 محفوظ. التقارير الأقدم داخل الحزمة تاريخية. قائمة ملفات هذه المراجعة بجانب هذا التقرير.
