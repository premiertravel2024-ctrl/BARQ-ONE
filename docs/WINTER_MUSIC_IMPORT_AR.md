# WINTER MUSIC — استيراد موسيقى المستخدم إلى BARQ ONE

الإصدار: 2.41.25

## طريقة الاستخدام على Windows

1. احفظ ملف المستخدم الأصلي **WINTER MUSIC.zip** (الذي يحتوي التسجيلات الثلاثة)، من دون فك ضغطه.
2. افتح **BARQ ONE ← الموسيقى ← مكتبتي**.
3. اضغط **استيراد WINTER MUSIC** واختر الملف `WINTER MUSIC.zip`.
4. بعد نجاح فحص الملفات، ينشئ برق قائمة تشغيل **WINTER MUSIC** ويعرض التسجيلات الثلاثة داخلها.
5. عند استيراد المجموعة مرة ثانية، يحدث نفس القائمة ولا ينشئ نسخة مكررة من كل تسجيل.
