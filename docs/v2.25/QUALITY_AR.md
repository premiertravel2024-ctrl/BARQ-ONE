# BARQ 2.25.0 — مراجعة جودة المشروع قبل التسليم

## التغيير الفعلي
أضيفت مراجعة محلية للملفات المسجلة في مهمة Python قبل اقتراح الاختبار أو بناء EXE. تفحص الصياغة والقراءة، والاستيراد من ملفات Python المحلية البسيطة مقابل الأسماء المصدرة فعليًا، والاختبارات الفارغة أو التي لا تفعل سوى تأكيد قيمة ثابتة صحيحة. المشاكل المانعة تذهب مع الكود إلى مخطط الإصلاح. الخطة الفارغة التي تدعي الاكتمال ترفض إذا بقيت مشاكل مانعة، حتى مع وجود نتيجة اختبارات ناجحة سابقة.

توليد الملف التالي يستقبل توقيعات الدوال وطرق الكلاسات الحقيقية (أسماء المعاملات والقيم الافتراضية)، بعد تنقيح المصدر، للمساعدة في الربط بين الملفات بدل الاكتفاء بأسماء الدوال. تعليمات التوليد تطلب فصل المنطق عن تشغيل الواجهة، معالجة المدخلات غير الصالحة وأخطاء الملفات، واختبارات سلوك فعلي، وتوثيق الميزات المنفذة والقيود وأوامر التشغيل. هذه التعليمات تحسن التوجيه وليست إثباتًا أن النموذج نفذ كل بند.

الفحص يقرأ ويحلل AST ولا يستورد أو يشغل ملفات المشروع. لا يمنح موافقة حفظ أو تشغيل. يترك التصدير الديناميكي والشرطي للاختبارات الفعلية لتجنب اتهامه خطأ. يظهر NotImplementedError كتنبيه يحتاج مراجعة وليس منعًا تلقائيًا لأنه قد يكون واجهة مجردة مقصودة.

## التحقق
أضيفت تسعة اختبارات تغطي توقيعات الدوال، استيراد دالة محلية مفقودة، أربعة أشكال لاختبارات شكلية، السماح بالتصدير الديناميكي، عدم تنفيذ المصدر أثناء المراجعة، ورفض اكتمال المهمة مع مشاكل مانعة. الفحص الشامل النهائي: 889 ناجحًا و65 اختبارًا فرعيًا. بناء TypeScript/Vite ناجح. اختبارات المتصفح تؤكد مسار توليد وموافقة وحفظ وتعثر معلوم، واختبار صحة تشغيل السورس ناجح.

أول تشغيل للفحص الشامل تداخل مع بناء الواجهة الذي يعيد إنشاء ملفات الإنتاج، فأخفق اختبار صحة صفحة React. أُعيد الفحص بعد اكتمال البناء؛ لا يتطلب ذلك إخفاء الاختبار أو تعطيله. السجل الأول محفوظ مع السجل النهائي.

## حدود مهمة
هذا تطوير محدد للجودة، وليس وعدًا بمنتج احترافي مكتمل من أي طلب أو أي نموذج. المراجعة تخص ملفات Python المسجلة في المهمة، ولا تتحقق من كل الاستيرادات النسبية أو الخارجية أو صحة تصميم الواجهة أو تغطية كل متطلبات المستخدم. اكتشاف الاختبارات الشكلية محافظ وليس بديلًا عن قياس التغطية واختبار المستخدم. لم يتم تشغيل نموذج حي أو Windows EXE هنا. تحذير Starlette/httpx وخط GE SS الاختياري وحجم JavaScript ما زالوا موجودين.

## الاستخدام
فك الحزمة في مجلد جديد ثم شغل BUILD_BARQ.bat على Windows. استخدم مجلد مشروعك الحالي عند الاستكمال. السورس يتضمن إصلاحات التعافي وتنسيق مساحة العمل السابقة. النتائج والتقارير التاريخية تخص إصداراتها.
